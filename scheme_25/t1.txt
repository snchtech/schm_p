## Найважливіше — бібліотеки node_modules

У `package.json` потрібно правильно розділити залежності:

- `dependencies` — Express, OracleDB та інші бібліотеки, необхідні для роботи API.
- `devDependencies` — Nodemon, ESLint, Jest та інструменти, потрібні лише під час розробки.

Для production використовується:

```
npm ci --omit=dev
```

Це встановить лише production-залежності та необхідні їм транзитивні пакети.

## Запуск двох режимів

Development:

```
docker compose -f compose.yaml -f compose.dev.yaml up --build -d
```

Production:

```
docker compose -f compose.yaml -f compose.prod.yaml up --build -d
```

Обидва режими працюватимуть через Docker Engine у WSL2 Ubuntu без Docker Desktop.

У TXT також є готові `Dockerfile`, `compose.yaml`, `compose.dev.yaml`, `compose.prod.yaml`, налаштування Oracle 21, змінних середовища, томів для `node_modules` і покрокова перевірка.

Для твого проєкту я рекомендую саме цю структуру, а згодом додати Next.js + Konva як окремий сервіс до Docker Compose. Це дозволить локально розробляти обидві частини системи, а для production створювати незалежні оптимізовані образи API та frontend.
