Підготував інтеграцію `withTransaction()` у твій `documentSaveService` для одночасного збереження JSON Snapshot, NODE, EDGE та їхніх атрибутів в Oracle 21c.

### Що реалізовано

- Frontend: один запит `PUT /api/documents/:versionId/snapshot` із уже сформованим JSON.
- API: `documentController` передає дані в `documentSaveService`.
- Oracle: `withTransaction()` виконує всі SQL-операції через одне з'єднання.
- DOC_SNAPSHOT: перше збереження — `INSERT`, наступні — `UPDATE` того самого запису.
- DOC_OBJECT: `MERGE` для NODE та EDGE без створення дублікатів.
- DOC_OBJECT_ATTRIBUTE: оновлення індексованих атрибутів.
- Контроль помилок: `ROLLBACK` усіх змін, якщо будь-яка операція не виконалася.
