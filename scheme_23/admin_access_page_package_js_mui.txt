======================================================================
1. МЕТА
======================================================================

Реалізувати сторінку адміністрування доступів, яка дозволяє:

- відкривати сторінку лише користувачу з роллю administrator;
- шукати користувача;
- переглядати призначені йому ролі;
- призначати одну або декілька ролей;
- задавати scope для ролі;
- додатково виставляти permissions;
- зберігати зміни;
- поки працювати без БД через mock repository;
- у майбутньому замінити mock repository на API/БД без зміни UI;
- використовувати MUI;
- вписуватись у Feature-Sliced Design;
- працювати на JavaScript, без TypeScript.

======================================================================
3. ЗАГАЛЬНИЙ СЦЕНАРІЙ РОБОТИ
======================================================================

1. Користувач відкриває /admin/access.
2. AdminPageGuard перевіряє:
   can(currentUser, PERMISSIONS.ROLE_MANAGE, globalResource)
3. Якщо права немає:
   показується сторінка «Доступ заборонено».
4. Якщо користувач administrator:
   відкривається адміністративна сторінка.
5. Адміністратор вводить ім’я або email користувача.
6. Mock repository повертає список користувачів.
7. Адміністратор вибирає користувача.
8. Завантажуються roleAssignments і permissionOverrides.
9. Адміністратор змінює ролі, scope і permissions.
10. Натискає «Зберегти».
11. Store викликає repository.saveUserAccess().
12. Поки що зміни зберігаються у пам’яті mock repository.
13. Пізніше repository буде замінений на API.

import {
  MOCK_USERS,
} from "@/entities/user/model/mockUsers";

const delay = (ms) => {
  return new Promise((resolve) => {
    setTimeout(resolve, ms);
  });
};

let usersDatabase =
  structuredClone(MOCK_USERS);

function normalizeText(value) {
  return String(value || "")
    .trim()
    .toLowerCase();
}

export const mockAdminAccessRepository = {
  async searchUsers(query) {
    await delay(250);

    const normalizedQuery =
      normalizeText(query);

    if (!normalizedQuery) {
      return usersDatabase.map(
        (user) => ({
          id: user.id,
          name: user.name,
          email: user.email,
          departmentIds:
            user.departmentIds,
        })
      );
    }

    return usersDatabase
      .filter((user) => {
        const name =
          normalizeText(user.name);

        const email =
          normalizeText(user.email);

        return (
          name.includes(normalizedQuery)
          || email.includes(
            normalizedQuery
          )
        );
      })
      .map((user) => ({
        id: user.id,
        name: user.name,
        email: user.email,
        departmentIds:
          user.departmentIds,
      }));
  },

  async getUserAccess(userId) {
    await delay(200);

    const user =
      usersDatabase.find(
        (item) =>
          item.id === userId
      );

    if (!user) {
      throw new Error(
        "Користувача не знайдено"
      );
    }

    return structuredClone({
      user: {
        id: user.id,
        name: user.name,
        email: user.email,
        departmentIds:
          user.departmentIds,
        positions:
          user.positions || [],
      },

      roleAssignments:
        user.roleAssignments || [],

      permissionOverrides:
        user.permissionOverrides || [],
    });
  },

  async saveUserAccess(
    userId,
    accessData
  ) {
    await delay(400);

    const index =
      usersDatabase.findIndex(
        (item) =>
          item.id === userId
      );

    if (index === -1) {
      throw new Error(
        "Користувача не знайдено"
      );
    }

    usersDatabase[index] = {
      ...usersDatabase[index],

      roleAssignments:
        structuredClone(
          accessData.roleAssignments
        ),

      permissionOverrides:
        structuredClone(
          accessData.permissionOverrides
        ),
    };

    return structuredClone({
      userId,

      roleAssignments:
        usersDatabase[index]
          .roleAssignments,

      permissionOverrides:
        usersDatabase[index]
          .permissionOverrides,
    });
  },
};

Примітка:

structuredClone підтримується у сучасних браузерах і Node.js.
Якщо середовище старіше:

const clone = (value) =>
  JSON.parse(JSON.stringify(value));

import { create } from "zustand";
import {
  adminAccessApi,
} from "../api";

function createId(prefix) {
  return (
    `${prefix}-`
    + Date.now()
    + "-"
    + Math.random()
      .toString(36)
      .slice(2, 8)
  );
}

export const useAdminAccessStore =
  create((set, get) => ({
    searchQuery: "",
    searchResults: [],
    selectedUserId: null,
    selectedUser: null,

    roleAssignments: [],
    permissionOverrides: [],

    isSearching: false,
    isLoadingUser: false,
    isSaving: false,

    searchError: null,
    loadError: null,
    saveError: null,
    saveSuccess: false,

    setSearchQuery: (
      searchQuery
    ) => {
      set({
        searchQuery,
        searchError: null,
      });
    },

    searchUsers: async () => {
      const query =
        get().searchQuery;

      set({
        isSearching: true,
        searchError: null,
      });

      try {
        const searchResults =
          await adminAccessApi
            .searchUsers(query);

        set({
          searchResults,
          isSearching: false,
        });
      } catch (error) {
        set({
          isSearching: false,
          searchError:
            error.message
            || "Помилка пошуку",
        });
      }
    },

    selectUser: async (
      userId
    ) => {
      set({
        selectedUserId: userId,
        selectedUser: null,
        roleAssignments: [],
        permissionOverrides: [],
        isLoadingUser: true,
        loadError: null,
        saveError: null,
        saveSuccess: false,
      });

      try {
        const data =
          await adminAccessApi
            .getUserAccess(userId);

        set({
          selectedUser:
            data.user,

          roleAssignments:
            data.roleAssignments,

          permissionOverrides:
            data.permissionOverrides,

          isLoadingUser: false,
        });
      } catch (error) {
        set({
          isLoadingUser: false,
          loadError:
            error.message
            || "Помилка завантаження",
        });
      }
    },

    addRoleAssignment: () => {
      set((state) => ({
        roleAssignments: [
          ...state.roleAssignments,
          {
            id: createId(
              "role-assignment"
            ),
            roleId: "reader",
            scope: {
              type: "department",
              id:
                state.selectedUser
                  ?.departmentIds?.[0]
                || "",
            },
          },
        ],

        saveSuccess: false,
      }));
    },

    updateRoleAssignment: (
      assignmentId,
      patch
    ) => {
      set((state) => ({
        roleAssignments:
          state.roleAssignments.map(
            (assignment) => {
              if (
                assignment.id
                !== assignmentId
              ) {
                return assignment;
              }

              return {
                ...assignment,
                ...patch,

                scope: patch.scope
                  ? {
                      ...assignment.scope,
                      ...patch.scope,
                    }
                  : assignment.scope,
              };
            }
          ),

        saveSuccess: false,
      }));
    },

    removeRoleAssignment: (
      assignmentId
    ) => {
      set((state) => ({
        roleAssignments:
          state.roleAssignments.filter(
            (assignment) =>
              assignment.id
              !== assignmentId
          ),

        saveSuccess: false,
      }));
    },

    togglePermissionOverride: ({
      permission,
      effect,
      scope,
    }) => {
      set((state) => {
        const existing =
          state.permissionOverrides
            .find((item) => {
              return (
                item.permission
                  === permission
                && item.effect
                  === effect
                && item.scope.type
                  === scope.type
                && item.scope.id
                  === scope.id
              );
            });

        if (existing) {
          return {
            permissionOverrides:
              state.permissionOverrides
                .filter(
                  (item) =>
                    item.id
                    !== existing.id
                ),

            saveSuccess: false,
          };
        }

        return {
          permissionOverrides: [
            ...state.permissionOverrides,
            {
              id: createId(
                "permission-override"
              ),
              permission,
              effect,
              scope,
            },
          ],

          saveSuccess: false,
        };
      });
    },

    saveUserAccess: async () => {
      const {
        selectedUserId,
        roleAssignments,
        permissionOverrides,
      } = get();

      if (!selectedUserId) {
        set({
          saveError:
            "Спочатку виберіть користувача",
        });

        return false;
      }

      set({
        isSaving: true,
        saveError: null,
        saveSuccess: false,
      });

      try {
        await adminAccessApi
          .saveUserAccess(
            selectedUserId,
            {
              roleAssignments,
              permissionOverrides,
            }
          );

        set({
          isSaving: false,
          saveSuccess: true,
        });

        return true;
      } catch (error) {
        set({
          isSaving: false,
          saveError:
            error.message
            || "Помилка збереження",
        });

        return false;
      }
    },

    reset: () => {
      set({
        searchQuery: "",
        searchResults: [],
        selectedUserId: null,
        selectedUser: null,
        roleAssignments: [],
        permissionOverrides: [],
        isSearching: false,
        isLoadingUser: false,
        isSaving: false,
        searchError: null,
        loadError: null,
        saveError: null,
        saveSuccess: false,
      });
    },
  }));

export function validateAccessForm({
  roleAssignments,
}) {
  const errors = [];

  roleAssignments.forEach(
    (assignment, index) => {
      if (!assignment.roleId) {
        errors.push(
          `Роль №${index + 1}: не вибрана роль`
        );
      }

      if (
        !assignment.scope
        || !assignment.scope.type
      ) {
        errors.push(
          `Роль №${index + 1}: не вибраний scope`
        );
      }

      if (
        assignment.scope?.type
          !== "global"
        && !assignment.scope?.id
      ) {
        errors.push(
          `Роль №${index + 1}: не вибраний об’єкт scope`
        );
      }
    }
  );

  const hasDuplicate =
    roleAssignments.some(
      (assignment, index) => {
        return roleAssignments.some(
          (
            comparedAssignment,
            comparedIndex
          ) => {
            return (
              index
                !== comparedIndex
              && assignment.roleId
                === comparedAssignment.roleId
              && assignment.scope?.type
                === comparedAssignment.scope?.type
              && assignment.scope?.id
                === comparedAssignment.scope?.id
            );
          }
        );
      }
    );

  if (hasDuplicate) {
    errors.push(
      "Є дублікати однакових ролей у тому самому scope"
    );
  }

  return {
    isValid:
      errors.length === 0,
    errors,
  };
}

"use client";

import {
  Alert,
  Box,
  Button,
  CircularProgress,
  Paper,
  Typography,
} from "@mui/material";

import { useRouter } from "next/navigation";

import {
  PERMISSIONS,
  can,
  useAuthStore,
} from "@/features/auth";

const ADMIN_RESOURCE = {
  type: "global",
  id: "admin-access",
};

export function AdminPageGuard({
  children,
}) {
  const router = useRouter();

  const currentUser =
    useAuthStore(
      (state) =>
        state.currentUser
    );

  const isInitialized =
    useAuthStore(
      (state) =>
        state.isInitialized
    );

  if (!isInitialized) {
    return (
      <Box
        sx={{
          minHeight: "50vh",
          display: "grid",
          placeItems: "center",
        }}
      >
        <CircularProgress />
      </Box>
    );
  }

  const allowed = can(
    currentUser,
    PERMISSIONS.ROLE_MANAGE,
    ADMIN_RESOURCE
  );

  if (!allowed) {
    return (
      <Box
        sx={{
          maxWidth: 720,
          mx: "auto",
          py: 6,
          px: 2,
        }}
      >
        <Paper
          variant="outlined"
          sx={{
            p: 4,
          }}
        >
          <Alert
            severity="error"
            sx={{
              mb: 3,
            }}
          >
            Доступ заборонено
          </Alert>

          <Typography
            variant="h5"
            component="h1"
            gutterBottom
          >
            У вас немає прав для
            керування ролями
          </Typography>

          <Typography
            color="text.secondary"
            sx={{
              mb: 3,
            }}
          >
            Ця сторінка доступна
            лише користувачу з
            адміністративним дозволом
            role.manage.
          </Typography>

          <Button
            variant="contained"
            onClick={() => {
              router.push("/");
            }}
          >
            На головну
          </Button>
        </Paper>
      </Box>
    );
  }

  return children;
}

  CircularProgress,
  TextField,
} from "@mui/material";

import {
  useAdminAccessStore,
} from "../model/useAdminAccessStore";

export function UserSearch() {
  const searchQuery =
    useAdminAccessStore(
      (state) =>
        state.searchQuery
    );

  const searchResults =
    useAdminAccessStore(
      (state) =>
        state.searchResults
    );

  const selectedUserId =
    useAdminAccessStore(
      (state) =>
        state.selectedUserId
    );

  const isSearching =
    useAdminAccessStore(
      (state) =>
        state.isSearching
    );

  const searchError =
    useAdminAccessStore(
      (state) =>
        state.searchError
    );

  const setSearchQuery =
    useAdminAccessStore(
      (state) =>
        state.setSearchQuery
    );

  const searchUsers =
    useAdminAccessStore(
      (state) =>
        state.searchUsers
    );

  const selectUser =
    useAdminAccessStore(
      (state) =>
        state.selectUser
    );

  const selectedOption =
    searchResults.find(
      (user) =>
        user.id
        === selectedUserId
    ) || null;

  return (
    <Box>
      <Box
        sx={{
          display: "grid",
          gridTemplateColumns: {
            xs: "1fr",
            md: "1fr auto",
          },
          gap: 2,
          alignItems: "start",
        }}
      >
        <Autocomplete
          options={
            searchResults
          }
          value={
            selectedOption
          }
          loading={
            isSearching
          }
          filterOptions={(options) =>
            options
          }
          getOptionLabel={(
            option
          ) => {
            if (!option) {
              return "";
            }

            return (
              `${option.name} — `
              + option.email
            );
          }}
          isOptionEqualToValue={(
            option,
            value
          ) => {
            return (
              option.id
              === value.id
            );
          }}
          onInputChange={(
            event,
            value,
            reason
          ) => {
            if (
              reason === "input"
              || reason === "clear"
            ) {
              setSearchQuery(value);
            }
          }}
          onChange={(
            event,
            value
          ) => {
            if (value?.id) {
              selectUser(value.id);
            }
          }}
          renderInput={(params) => (
            <TextField
              {...params}
              label="Пошук користувача"
              placeholder={
                "Введіть ім’я або email"
              }
              value={searchQuery}
              InputProps={{
                ...params.InputProps,
                endAdornment: (
                  <>
                    {isSearching && (
                      <CircularProgress
                        size={18}
                      />
                    )}

                    {
                      params.InputProps
                        .endAdornment
                    }
                  </>
                ),
              }}
            />
          )}
        />

        <Button
          variant="outlined"
          disabled={isSearching}
          onClick={searchUsers}
          sx={{
            minHeight: 56,
          }}
        >
          Знайти
        </Button>
      </Box>

      {searchError && (
        <Alert
          severity="error"
          sx={{
            mt: 2,
          }}
        >
          {searchError}
        </Alert>
      )}
    </Box>
  );
}

export function RoleAssignmentCard({

"use client";

import {
  Accordion,
  AccordionDetails,
  AccordionSummary,
  Box,
  Chip,
  FormControl,
  FormControlLabel,
  FormLabel,
  MenuItem,
  Radio,
  RadioGroup,
  Select,
  Stack,
  Switch,
  Typography,
} from "@mui/material";

import ExpandMoreIcon
  from "@mui/icons-material/ExpandMore";

import {
  MANAGEABLE_PERMISSIONS,
  MOCK_DEPARTMENTS,
} from "../model/constants";

function groupPermissions() {
  return MANAGEABLE_PERMISSIONS
    .reduce((result, item) => {
      if (!result[item.group]) {
        result[item.group] = [];
      }

      result[item.group].push(
        item
      );

      return result;
    }, {});
}

const groupedPermissions =
  groupPermissions();

export function PermissionSelector({
  permissionOverrides,
  onToggle,
}) {
  const [
    effect,
    setEffect,
  ] = React.useState("allow");

  const [
    departmentId,
    setDepartmentId,
  ] = React.useState(
    MOCK_DEPARTMENTS[0]?.id
    || ""
  );

  function isSelected(
    permission
  ) {
    return permissionOverrides.some(
      (item) => {
        return (
          item.permission
            === permission
          && item.effect
            === effect
          && item.scope?.type
            === "department"
          && item.scope?.id
            === departmentId
        );
      }
    );
  }

  return (
    <Stack spacing={3}>
      <Box
        sx={{
          display: "grid",
          gridTemplateColumns: {
            xs: "1fr",
            md: "1fr 1fr",
          },
          gap: 2,
        }}
      >
        <FormControl>
          <FormLabel>
            Тип правила
          </FormLabel>

          <RadioGroup
            row
            value={effect}
            onChange={(event) => {
              setEffect(
                event.target.value
              );
            }}
          >
            <FormControlLabel
              value="allow"
              control={<Radio />}
              label="Дозволити"
            />

            <FormControlLabel
              value="deny"
              control={<Radio />}
              label="Заборонити"
            />
          </RadioGroup>
        </FormControl>

        <FormControl fullWidth>
          <FormLabel
            sx={{
              mb: 1,
            }}
          >
            Відділ
          </FormLabel>

          <Select
            value={departmentId}
            onChange={(event) => {
              setDepartmentId(
                event.target.value
              );
            }}
          >
            {
              MOCK_DEPARTMENTS.map(
                (department) => (
                  <MenuItem
                    key={department.id}
                    value={department.id}
                  >
                    {department.name}
                  </MenuItem>
                )
              )
            }
          </Select>
        </FormControl>
      </Box>

      <Box>
        {
          Object.entries(
            groupedPermissions
          ).map(
            ([
              group,
              permissions,
            ]) => (
              <Accordion
                key={group}
                disableGutters
              >
                <AccordionSummary
                  expandIcon={
                    <ExpandMoreIcon />
                  }
                >
                  <Typography
                    fontWeight={600}
                  >
                    {group}
                  </Typography>
                </AccordionSummary>

                <AccordionDetails>
                  <Stack spacing={1}>
                    {
                      permissions.map(
                        (permission) => {
                          const checked =
                            isSelected(
                              permission.id
                            );

                          return (
                            <FormControlLabel
                              key={
                                permission.id
                              }
                              control={
                                <Switch
                                  checked={
                                    checked
                                  }
                                  onChange={() => {
                                    onToggle({
                                      permission:
                                        permission.id,

                                      effect,

                                      scope: {
                                        type:
                                          "department",
                                        id:
                                          departmentId,
                                      },
                                    });
                                  }}
                                />
                              }
                              label={
                                permission.label
                              }
                            />
                          );
                        }
                      )
                    }
                  </Stack>
                </AccordionDetails>
              </Accordion>
            )
          )
        }
      </Box>

      {
        permissionOverrides.length
          > 0
        && (
          <Box>
            <Typography
              variant="subtitle2"
              sx={{
                mb: 1,
              }}
            >
              Активні винятки
            </Typography>

            <Stack
              direction="row"
              spacing={1}
              useFlexGap
              flexWrap="wrap"
            >
              {
                permissionOverrides.map(
                  (item) => (
                    <Chip
                      key={item.id}
                      color={
                        item.effect
                          === "allow"
                          ? "success"
                          : "error"
                      }
                      label={
                        `${item.effect}: `
                        + item.permission
                        + " / "
                        + (
                          item.scope?.id
                          || item.scope?.type
                        )
                      }
                    />
                  )
                )
              }
            </Stack>
          </Box>
        )
      }
    </Stack>
  );
}

          </Stack>
        )}

            permissionOverrides={
              permissionOverrides
            }
            onToggle={
              togglePermissionOverride
            }
          />
        )}
      </Box>

          p: 2,
          display: "flex",
          justifyContent: "flex-end",

          onClick={handleSave}

          Зберегти

async function parseResponse(
  response
) {
  if (!response.ok) {
    const errorData =
      await response.json()
        .catch(() => null);

    throw new Error(
      errorData?.message
      || "Помилка API"
    );
  }

  return response.json();
}

export const apiAdminAccessRepository = {
  async searchUsers(query) {
    const params =
      new URLSearchParams();

    if (query) {
      params.set(
        "search",
        query
      );
    }

    const response =
      await fetch(
        `/api/admin/users?${params}`,
        {
          method: "GET",
          credentials: "include",
        }
      );

    return parseResponse(
      response
    );
  },

  async getUserAccess(userId) {
    const response =
      await fetch(
        `/api/admin/users/${userId}/access`,
        {
          method: "GET",
          credentials: "include",
        }
      );

    return parseResponse(
      response
    );
  },

  async saveUserAccess(
    userId,
    accessData
  ) {
    const response =
      await fetch(
        `/api/admin/users/${userId}/access`,
        {
          method: "PUT",
          credentials: "include",
          headers: {
            "Content-Type":
              "application/json",
          },
          body: JSON.stringify(
            accessData
          ),
        }
      );

    return parseResponse(
      response
    );
  },
};

23. ПЕРЕВІРКА НА SERVER
======================================================================

Frontend guard не є достатнім.

Кожен admin endpoint повинен:

1. отримати користувача із server session;
2. перевірити його роль/permission;
3. відхилити запит із 403, якщо немає role.manage;
4. не довіряти currentUser із Zustand;
5. перевірити дані roleAssignments;
6. виконати транзакцію в БД;
7. записати audit log.

Умовний server helper:

export async function assertAdministrator(
  sessionUser
) {
  const allowed =
    await serverCan(
      sessionUser.id,
      "role.manage",
      {
        type: "global",
      }
    );

  if (!allowed) {
    const error =
      new Error(
        "Forbidden"
      );

    error.status = 403;

    throw error;
  }
}

26. БЕЗПЕКА ВИДАЧІ ADMINISTRATOR
======================================================================

Окремо рекомендується обмежити видачу administrator.

Не кожен administrator обов’язково повинен мати право
призначати інших administrator.

Можна додати permission:

role.assignAdministrator

Тоді:

- role.manage дозволяє видавати reader/editor;
- role.assignAdministrator дозволяє видавати administrator.

У RoleAssignmentCard:

const canAssignAdministrator =
  useCan(
    PERMISSIONS
      .ROLE_ASSIGN_ADMINISTRATOR,
    ADMIN_RESOURCE
  );

AVAILABLE_ROLES.filter(
  (role) => {
    if (
      role.id
        !== "administrator"
    ) {
      return true;
    }

    return canAssignAdministrator;
  }
);

На backend ця перевірка обов’язкова.

27. UX-РЕКОМЕНДАЦІЇ
======================================================================

1. Перед збереженням показувати попередження,
   якщо користувачу видається administrator.

2. Для critical roles можна додати Dialog підтвердження.

3. Permission overrides показувати окремо від ролей,
   щоб користувач не плутав базові ролі та винятки.

4. Використовувати deny дуже обережно.

5. Не дозволяти дублікати однакових role assignments.

6. Показувати effective permissions окремою read-only вкладкою.

7. Показувати, звідки permission отримано:
   role / position / override.

8. Після збереження оновлювати auth session користувача
   або інвалідовувати permission cache.

31. ГОЛОВНА РЕКОМЕНДАЦІЯ
======================================================================

UI не повинен напряму працювати з MOCK_USERS.

UI працює тільки через adminAccessApi.

Зараз:

adminAccessApi =
  mockAdminAccessRepository

Пізніше:

adminAccessApi =
  apiAdminAccessRepository

Завдяки цьому:

- сторінка не змінюється;
- MUI-компоненти не змінюються;
- Zustand store майже не змінюється;
- змінюється лише джерело даних;
- логіка готова до БД;
- FSD залишається збереженим;
- доступ до сторінки централізовано захищений.
